# ballsdex-tutorial

**A Ballsdex extension package that adds a tutorial command.** Users can see how can they use the bot via the `/tutorial` command.

## Installation

Add the following into your `config/extra.toml` file.

```toml
[[ballsdex.packages]]
location = "git+https://github.com/seiftheman/ballsdex-tutorial.git#main"
path = "tutorial"
enabled = true
```
